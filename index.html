Demo overview

  • Baselines: FreeVC and StarGANv2-VC
  • Proposed method: MS WSAS-VC
  • Four conversion conditions with two shared utterances
  • Reusable original source and target audio files
Male → Male Female → Female Male → Female Female → Male Directory

How to edit: Put the two shared sentences in sharedUtterances. Then edit speaker names and speaker pairs in demoData. Original audio is loaded from assets/wavs/original/{speaker}/{utt_id}.wav, so the same source or target original file can be reused by multiple conditions.

Recommended audio directory structure

Each gender condition uses one representative speaker pair. Cross-gender conditions are not expanded to all M/F combinations. Original speech is separated from converted speech so that the same original files can be referenced from multiple conversion conditions.
